Overview

This is a simple and interactive task management application designed to help users organize and track their daily activities.

Problem

Many people struggle to stay organized with daily tasks. Simple tools are often either too complex or not engaging enough.

Solution

I built a lightweight and user-friendly task app that allows users to easily add, complete, and manage tasks in a clean interface.

Features

  • Add new tasks
  • Mark tasks as completed
  • Simple and clean interface
  • Interactive user experience

Technologies

HTML, CSS, JavaScript

What I Learned

This project helped me improve my JavaScript skills, especially working with DOM manipulation and handling user interactions.
